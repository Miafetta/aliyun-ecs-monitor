# 故障排查

## 容器未运行或反复重启

运行 `docker compose ps -a` 和 `docker compose logs --tail=100 monitor` 查看状态与错误。确认 Docker 服务正常，项目目录中存在 `accounts.json` 和 `webhook.txt`，且容器可以读取文件。

启动后应看到 `Monitor started`，每轮完成后显示 `Check completed: ok` 或 `failed`。容器为运行状态不代表查询成功；查询和通知失败会在后续轮次重试。请检查服务器到阿里云、飞书的 DNS、HTTPS 连接及系统时间。

提示 `Another monitor is using this state directory` 时，停止共享该数据卷的其他写入进程，不要删除运行中服务的锁文件。不要在多个服务器同时控制相同实例。

## 权限策略创建或授权失败

- 策略名称使用 `ECS-Monitor` 等仅含英文字母、数字和中划线的名称。
- `cdt:ListCdtInternetTraffic` 等是 JSON 中的 `Action`。先创建自定义策略，再在 RAM 用户的授权页面选择该策略名称。
- 资源 ARN 中填写实例所属主账号的数字 UID；AccessKey ID 填写在监控账号配置中。
- 核对 ARN 中的地域与实例 ID，确保每个受监控实例均已列入启停授权范围。

权限策略和账号配置示例见 [部署说明](../README.md#部署)。

## 配置被拒绝

`accounts.json` 必须是非空 JSON 数组，不支持注释。检查字段拼写、JSON 格式及以下要求：

- 账号名称和 AccessKey ID 不重复，每个账号至少配置一个实例。
- 阈值为有限的非负数；`paused` 为 `true` 或 `false`，不加引号。
- 实例 ID 和地域填写正确；配置中不包含额外字段。
- `REPORT_HOUR` 为空时使用默认值 `5`，设置时应为 `0`～`23` 的整数。

## Account query failed / control withheld

该错误表示本轮已跳过对应账号的全部控制，其他账号仍继续处理。先运行只读诊断，检查 RAM 权限、实例 ID、地域和网络。

CDT 响应必须包含非空的 `TrafficDetails`。每行需包含受支持的 `BusinessRegionId` 和非负整数字节 `Traffic`；同一地域与 ISP 的重复组合会被拒绝，嵌套产品和阶梯明细不会重复计算。受监控流量池缺失时不会按零用量处理。

未知地域会阻止控制；如需添加地域，请核实分类后更新 `src/monitor.py` 中的 `REGIONS`。所有未暂停实例状态均查询成功后，才开始该账号的控制。

## 飞书发送失败

确认 Webhook 来自飞书群聊自定义机器人，安全设置使用关键词 `ECS Monitor`，签名校验关闭；如启用 IP 白名单，需允许服务器公网出口地址。

发送成功要求 HTTP 状态为 `200`，且响应业务 `code` 为整数 `0`。失败时不会更新通知冷却或日报日期，本轮日志会显示失败。通知失败不会撤回已提交的启停请求，也不会阻塞必要的控制。

## 实例自动开机或未立即关机

人工关机的实例也会在共享池用量低于阈值时自动启动，维护前应设置 `paused: true`。暂停的实例不执行控制。

共享池达到阈值后才提交关机请求，默认不强制断电。控制面、用量更新及调度均有延迟；请求被接受后，还需后续查询确认实例状态。

## 日报未发送或重复

日报在当天北京时间指定小时之后首次成功运行时发送。任一账号查询、控制请求或通知失败时暂缓，后续成功再发。

状态数据卷丢失、卡片部分发送失败或账号名称变化均可能导致重复通知。请保持账号名称稳定，避免多个服务同时控制同一实例。

## 修改配置未生效

确认文件内容有效。若编辑器通过替换文件保存配置，执行 `docker compose up -d --force-recreate` 刷新文件挂载。修改 `.env` 后也需重新创建容器。

## 状态保存失败

确认状态数据卷可写、宿主机磁盘未满。不要删除数据卷或执行 `docker compose down -v`；丢失状态可能导致重复通知和重复提交操作。

## 系统安装问题

参阅 [安装说明](../system-setup/00-README.zh-CN.md)。分段校验失败时重新粘贴对应段，等待每段显示 `OK` 后再继续。

内存检查以 Linux 的 `MemTotal` 为准，套餐标称容量不等于系统实际可见内存。网络、下载或分区错误应在 VNC 中查看具体提示；不要绕过校验或在分区期间强制断电。清盘后需要通过快照或备份恢复旧数据。
